[ 무엇 ]
HTML 슬라이드 덱(1920×1080)을 PowerPoint에서 직접 수정 가능한 PPT로 변환.
- 모든 글자 = 진짜 편집 가능한 텍스트
- 도형·통계박스·이미지 = 네이티브 요소
- 쓰인 폰트 자동 감지 → 없는 폰트 원클릭 설치 → PPT에 임베드
- ★ AI 사용 안 함 · API 키/로그인/비용 없음 · 로컬에서만 동작


[ 실행 ]
바탕화면 "HTML을 PPT로 변환" 아이콘 더블클릭  → 앱 창이 열립니다.
(또는 폴더의 "HTML을 PPT로 변환.bat")


[ 쓰는 법 ]
1) 앱에서 "HTML 파일 선택" 클릭 → 변환할 HTML 고르기 (여러 개 가능)
   · 또는 HTML 파일을 바탕화면 아이콘에 끌어다 놓기
2) "이 덱이 쓰는 폰트" 패널에서 없는 폰트가 있으면 [설치] 클릭
   (또는 "없는 폰트 모두 설치")
3) "PPT로 변환" 클릭 → 결과 PPT가 원본과 같은 폴더에 생깁니다
4) "폴더에서 보기"로 결과 확인


[ 필요 환경 ]
- Google Chrome (또는 Edge)   ← 렌더링 (필수)
- Node.js                     ← 변환 엔진 (필수)
- Microsoft PowerPoint        ← 폰트 임베드 (없어도 PPT는 생성됨)


[ 다른 회사와 공유 ]
- AI/키/과금 없음 → 받는 쪽 비용 0
- 받는 PC도 Node.js + Chrome 필요 (설치메모.txt 참고)
- PowerPoint가 있으면 폰트가 자동 임베드되어 어디서나 동일하게 보임
